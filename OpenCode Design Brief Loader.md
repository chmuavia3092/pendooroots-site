The final result should look like it was created by a professional brand/design team—not generated by an AI from a generic website template.

Prioritize:

- strong visual hierarchy
- intentional whitespace
- consistent grid
- controlled typography
- restrained colors
- premium imagery
- editorial composition
- cinematic storytelling

- responsive design
- accessibility
- performance

- excessive gradients
- random icons
- decorative blobs
